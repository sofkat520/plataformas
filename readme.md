## 🏛️ Detalle de la Entrega Actual: Portal Institucional "Diálogo y Desarrollo"

Para el laboratorio de **IA Generativa en Desarrollo Web**, se diseñó y refinó el sitio web para la ONG peruana **"Diálogo y Desarrollo"**, enfocada en el análisis político y ambiental.

* **HTML5 Semántico**
* **Tailwind CSS** (vía CDN)
* **JavaScript Vanilla** (para interactividad de menú y reproductores)
* **Asistentes de IA:** Gemini / ChatGPT
